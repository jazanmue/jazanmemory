# ذاكرة جازان

موقع أرشيف رقمي جاهز للرفع على GitHub Pages.

## طريقة الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع كل ملفات ومجلدات هذا المشروع كما هي.
3. تأكد أن ملف `index.html` موجود في الجذر.
4. من Settings ثم Pages اختر الفرع `main` والمجلد `/root`.
5. افتح رابط GitHub Pages بعد التفعيل.

## صفحات الموقع
- `index.html` الصفحة الرئيسية
- `documents.html` الأرشيف والوثائق والصكوك
- `board.html` لوحة الذكريات والمنشورات
- `admin.html` لوحة التحكم
